# flow.hover

Move the pointer over a target to expose hover behavior.

## Example

```flow
flow.hover "Products";
```

## Behavior and limits

Assert the menu or tooltip you expect afterward. Phone emulation does not imply hover is a real touchscreen gesture.

Use this command inside a complete [Given/When/Then scenario](/guide/core-concepts). See the [browser command index](/reference/ui-commands) for related actions.
