Flowstride session storage example

This is a local demonstration application, not production authentication.

Install and run:
  npm i flowstride
  npx flowstride install
  npx flowstride run --ci

The example uses port 4174. Keep that port free.
Flowstride starts and stops app.mjs in CI. For an interactive run, start the application in a separate terminal with npm start, then run npx flowstride run.

Cloud is optional and includes free accounts. Authenticate with npx flowstride login to use features available to your workspace.
No hosted application account is required for this example.
