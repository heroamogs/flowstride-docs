## Welcome

Flowstride is a flow-first automation framework built for modern quality engineering.

Unlike traditional automation tools that require extensive programming knowledge, Flowstride allows you to describe business behaviour using a readable domain-specific language (DSL) while providing the power required for large-scale UI and API automation.

Whether you're writing your first automated test or maintaining thousands of scenarios across multiple teams, the documentation is organised to guide you from the fundamentals to the complete language specification.
